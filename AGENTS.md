# Правила работы с проектом

- Сначала изучать текущую структуру проекта, не переписывать все без необходимости.
- Сохранять существующую бизнес-логику, роутинг и данные.
- Делать изменения аккуратно, небольшими и поддерживаемыми.
- Использовать единую дизайн-систему: общие токены для цветов, отступов, скруглений, теней, типографики.
- Не дублировать стили, выносить повторяющиеся решения в общие компоненты/классы.
- Проверять адаптивность desktop/tablet/mobile.
- Проверять все hover/focus/active-состояния.
- Проверять, чтобы все кнопки, табы, фильтры, поиск, карточки и переходы работали хотя бы на фронтенде без бэкенда.
- Удалять мертвый код, неиспользуемые стили, визуальные ошибки и недочеты.
- Следовать этим правилам во всех дальнейших изменениях проекта.
